# Clinical Bridge

Interactive medical student tele-mentoring prototype.

## Run

Open `index.html` in a modern browser. No build or installation is required.

Alternatively, from the repository folder run `python -m http.server 8000` and open http://localhost:8000.

## Features

- Mentor search and specialty filtering
- Personal session planning and removal
- SBAR learning activity with immediate feedback
- Saved learning goals, reflections, and completion tracking
- Responsive layout

Plans and reflections are stored in browser localStorage and are not synchronized between devices. Mentors are fictional. Session planning does not contact a mentor, book a real appointment, or provide video calls. Do not enter patient identifiers. Educational demonstration only.

Fonts use Google Fonts when available, with local sans-serif fallbacks.
