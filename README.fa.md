# پروژهٔ المپیاد · پل بالینی (Clinical Bridge)

**نسخهٔ دوم راهنما — فارسی** · [English](README.md)

یک صفحهٔ وب تعاملی برای تله‌منتورینگ دانشجویان پزشکی؛ با هدف ارتباط با مدرسان بالینی، برنامه‌ریزی گفت‌وگوهای آموزشی و ثبت پیشرفت یادگیری.

## ایدهٔ پروژه

آموزش بالینی به دسترسی به استادان باتجربه وابسته است. فاصلهٔ جغرافیایی، اختلال در کارآموزی و شرایط بحرانی می‌توانند این دسترسی را محدود کنند. «پل بالینی» بررسی می‌کند که چگونه یک محیط آنلاین ساده می‌تواند ارتباط دانشجویان پزشکی و اینترن‌ها را با راهنمایان آموزشی حفظ کند و به تداوم یادگیری ساختاریافته کمک کند.

این مخزن شامل نمونهٔ اولیهٔ رابط کاربری برای نمایش تجربهٔ پیشنهادی دانشجو است. منظور از نسخهٔ دوم در این فایل، نسخهٔ فارسی مستندات است؛ قابلیت‌های نرم‌افزار تغییری نکرده‌اند.

## امکانات موجود

- **داشبورد یادگیری:** مشاهدهٔ جلسات برنامه‌ریزی‌شده و فعالیت‌های تکمیل‌شده.
- **یافتن منتور:** جست‌وجوی شش پروفایل فرضی بر اساس نام یا تخصص.
- **فیلتر تخصص:** داخلی، جراحی، کودکان، طب اورژانس، مغز و اعصاب و پزشکی خانواده.
- **برنامه‌ریز جلسات:** انتخاب منتور، تاریخ، ساعت و هدف یادگیری و امکان حذف برنامه.
- **یادگیری تعاملی:** تمرین چارچوب تحویل بالینی SBAR همراه با بازخورد فوری.
- **هدف‌گذاری و بازاندیشی:** ذخیرهٔ هدف پیش از جلسه و تأمل دربارهٔ آموخته‌ها پس از جلسه.
- **پیگیری پیشرفت:** نمایش وضعیت تکمیل سه فعالیت آموزشی.
- **ذخیره‌سازی محلی:** نگهداری برنامه‌ها و یادداشت‌ها در همان مرورگر.
- **طراحی واکنش‌گرا:** نمایش متناسب با صفحهٔ رایانه و تلفن همراه.

## راه‌اندازی سریع

برای اجرای این نسخه، نیازی به نصب بسته‌های نرم‌افزاری یا اجرای فرایند ساخت نیست.

### اجرای مستقیم

۱. مخزن را دانلود یا کلون کنید.
۲. فایل `index.html` را در یک مرورگر جدید باز کنید.

### اجرا با سرور محلی

پس از نصب Git و Python، دستورهای زیر را اجرا کنید:

```bash
git clone https://github.com/SoniaK-Lab/Project-Olympiad.git
cd Project-Olympiad
python -m http.server 8000
```

سپس نشانی [http://localhost:8000](http://localhost:8000) را در مرورگر باز کنید. اگر فرمان پایتون در سیستم شما `python3` است، از دستور `python3 -m http.server 8000` استفاده کنید.

مخزن خصوصی است؛ برای کلون‌کردن آن باید حساب گیت‌هاب شما دسترسی مجاز داشته باشد.

## روش استفاده

۱. وارد بخش **Find a mentor** شوید و بر اساس نام یا تخصص جست‌وجو کنید.
۲. گزینهٔ **Plan a conversation** را انتخاب کنید.
۳. تاریخ، ساعت و هدف یادگیری را وارد و جلسه را به برنامهٔ شخصی اضافه کنید.
۴. در بخش **My sessions** برنامه‌ها را مشاهده یا حذف کنید.
۵. در بخش **Learning hub** به پرسش SBAR پاسخ دهید و هدف و بازاندیشی خود را ذخیره کنید.
۶. برای مشاهدهٔ پیشرفت به **Overview** برگردید.

نام دکمه‌ها مطابق رابط فعلی انگلیسی نوشته شده است؛ این فایل فقط راهنمای فارسی پروژه است.

## فناوری‌ها

- HTML5
- CSS با چیدمان واکنش‌گرا
- جاوااسکریپت بدون فریم‌ورک
- فضای ذخیره‌سازی `localStorage` مرورگر
- فونت‌های Google Fonts با فونت جایگزین محلی

این نسخه بک‌اند، پایگاه داده یا ابزار ساخت ندارد.

## داده‌ها و حریم خصوصی

برنامهٔ جلسات، اهداف یادگیری، بازاندیشی‌ها و وضعیت تکمیل فعالیت‌ها با کلید `clinicalBridge` در `localStorage` مرورگر ذخیره می‌شوند.

- داده‌ها بین مرورگرها یا دستگاه‌ها همگام نمی‌شوند.
- پاک‌کردن داده‌های سایت، پیشرفت ذخیره‌شده را حذف می‌کند.
- برنامه، یادداشت‌ها یا اهداف ذخیره‌شده را به سرور ارسال نمی‌کند.
- بارگذاری فونت‌ها ممکن است باعث ارسال درخواست به سرویس Google Fonts شود.
- اطلاعات شناسایی بیماران، داده‌های بالینی محرمانه یا اطلاعات حساس را وارد نکنید.

## محدودیت‌های نمونهٔ اولیه

همهٔ منتورها فرضی هستند. افزودن جلسه فقط یک برنامهٔ شخصی می‌سازد و به معنای تماس با منتور، تأیید زمان آزاد، ارسال دعوت‌نامه یا رزرو واقعی نیست.

این نسخه حساب کاربری، احراز صلاحیت منتورها، پیام‌رسانی، تماس تصویری، اعلان، اتصال به تقویم یا پروندهٔ مشترک ندارد. محتوای آن برای نمایش آموزشی است و جایگزین نظارت بالینی یا توصیهٔ پزشکی اختصاصی برای بیمار نیست.

- درخواست رزرو و فرایند تأیید جلسه
- پیام‌رسانی امن و اتصال به جلسات تصویری

موارد بالا پیشنهادهای توسعه هستند و هنوز پیاده‌سازی نشده‌اند.

## توسعه و بررسی تغییرات

برای تغییر ظاهر یا تعامل‌ها، فایل `index.html` را ویرایش و صفحه را تازه‌سازی کنید. استفاده از سرور محلی، نشانی اجرای ثابت و رفتار یکسان‌تری برای ذخیره‌سازی فراهم می‌کند.

پیش از ثبت تغییرات، جست‌وجو و فیلتر منتورها، افزودن و حذف جلسه، بازخورد فعالیت آموزشی، حفظ پیشرفت پس از بارگذاری دوباره و نمایش در صفحه‌های کوچک را بررسی کنید.
