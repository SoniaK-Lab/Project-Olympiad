# پل بالینی

سامانهٔ فارسی تله‌منتورینگ پزشکی با ورود ChatGPT، نقش‌های مدیر، منتور و دانشجو، برنامه‌ریزی جلسات، تأیید حضور و ذخیرهٔ پیشرفت در پایگاه دادهٔ D1.

این نسخه به سرور نیاز دارد و با بازکردن مستقیم index.html به‌تنهایی کار نمی‌کند.

راهنمای نصب، شروع کار مدیر و مستندات API: [BACKEND.md](BACKEND.md)

کد رابط در source-ui، مسیرهای API در app/api/bridge و طرح پایگاه داده در db/schema.ts قرار دارد. کیس‌های آموزشی فرضی هستند.
