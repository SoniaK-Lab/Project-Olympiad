# نسخهٔ مستقل Cloudflare

این مسیر روی Worker موجود `clinical-bridge` و پایگاه D1 موجود `clinical-bridge-db` اجرا می‌شود؛ به Sites یا حساب ChatGPT وابسته نیست. دامنهٔ فعلی و Cloudflare Access موجود حفظ می‌شوند.

- فرم ثبت‌نام: کد ملی، ایمیل، رمز و تکرار رمز و انتخاب نقش دانشجو یا منتور. تا تأیید ایمیل، فقط درخواست موقت ۱۵ دقیقه‌ای ذخیره می‌شود و حساب و مجوزی ساخته نمی‌شود.
- کد ایمیل را Cloudflare Access با ارائه‌دهندهٔ `Clinical Bridge Email Code` می‌فرستد. `/access-login` همان مسیر حفاظت‌شدهٔ موجود است؛ امضای JWT، صادرکننده، مخاطب و انقضا سمت سرور بررسی می‌شوند. ایمیل تأییدشده باید دقیقاً با ایمیل درخواست موقت برابر باشد.
- پس از تأیید، حساب با نقش انتخاب‌شدهٔ دانشجو یا منتور ساخته و داشبورد باز می‌شود. فقط نقش دانشجو یا منتور پذیرفته می‌شود؛ نقش مدیر از فرم ثبت‌نام قابل انتخاب نیست. نقش در درخواست موقت ذخیره و فقط پس از تأیید ایمیل اعمال می‌شود. حساب قبلی با ایمیل تأییدشده به رکورد خودش متصل می‌شود و نقش و اطلاعاتش حفظ می‌شوند.
- ورودهای بعدی با کد ملی و رمز است. حساب‌های قبلی می‌توانند با کد ایمیل وارد شوند و از داشبورد یک بار کد ملی و رمز تعیین کنند.
- داشبورد شمارش‌ها و موارد واقعی را از D1 در محدودهٔ نقش نشان می‌دهد؛ دادهٔ ساختگی برای پرکردن نمودار یا کارت ندارد. موارد بدون منتور یا جلسه، حالت خالی دارند.
- رمز با PBKDF2-SHA256، نمک تصادفی و ۱۰۰٬۰۰۰ تکرار ذخیره می‌شود. کوکی نشست HttpOnly/Secure/SameSite است و نشست سرور هنگام خروج باطل می‌شود. محدودیت تلاش و اطلاعات تأیید در D1 نگه‌داری می‌شوند. کد ملی بررسی ساختاری دارد و جایگزین احراز هویت قانونی نیست.
- `base-runtime.mjs` نسخهٔ تثبیت‌شدهٔ بک‌اند و دارایی‌های فعلی Cloudflare است؛ `auth-worker.mjs` ورود، تأیید ایمیل و کنترل دسترسی را اعمال می‌کند و `pages.mjs` رابط ثبت‌نام و داشبورد است. هیچ کلید API یا رمز Cloudflare در این مسیر نیست.

آزمون:

```bash
node tests/cloudflare-auth.test.mjs
```

انتشار مجدد پس از ورود امن Wrangler در حساب مالک:

```bash
npx wrangler login
npx wrangler deploy --config cloudflare/wrangler.jsonc
```

مهاجرت‌های `migrations/0001_national_email_auth.sql` و `migrations/0002_signup_roles.sql` فقط یک بار روی پایگاه قبلی اعمال می‌شود. اجرای دوبارهٔ آن مجاز نیست؛ پیش از اجرای دستی، ستون‌ها را بررسی کنید. تنظیمات `ACCESS_TEAM_DOMAIN`، `ACCESS_AUD`، `ADMIN_EMAIL` و رازهای TURN از Worker موجود حفظ می‌شوند. جدول‌ها و نشست‌های قدیمی حذف نمی‌شوند؛ نشست‌های قدیمی برای ورود به مسیر جدید نیاز به تأیید ایمیل دارند.
